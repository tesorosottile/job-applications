# Feedback

The input to the monthly retro. Without this folder the retro has nothing but tracker
statistics, which are too thin to learn from.

**How to use it:** during Thursday review, when you correct a draft, spend 30 seconds writing
down *what* you changed and *why*. Not the corrected text — the rule behind the correction.

One file per session, named `YYYY-MM-DD.md`. Format is deliberately loose; bullets are fine.

## Example

```
# 2026-10-15

- Cut the opening line on the Frontier letter. It restated the job title back at them.
  Third time I've done this — the prompt should forbid it explicitly.
- The NERA letter used E11 and E13 again. Every letter is using the same two. The thesis
  evidence is stronger for economic consulting and it keeps getting skipped.
- Kept the Oxera one nearly as-is. That one was right.
- notes.md on the CRA draft ticked "no banned phrase" but the letter said "proven track
  record". The self-check is not actually running.
```

That last kind of entry is the most valuable thing in this folder — it catches the system
lying to itself.

## What makes a useful entry

- A correction you made **and the rule behind it** — "cut X" is less useful than "cut X
  because it restates the posting"
- Anything that made you wince
- Anything you kept unchanged (positive signal is signal)
- Any self-check that passed when it shouldn't have

## What to skip

- Typos and one-off phrasing tweaks
- Anything firm-specific that won't recur
